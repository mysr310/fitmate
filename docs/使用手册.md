# 健身管家 · 使用手册

**版本**：1.0 ｜ **平台**：Android ｜ **数据存储**：全部保存在手机本地，无需注册登录

---

## 1. 安装与首次使用

1. 从 GitHub Actions 下载 `fitmate-apk`（安装前允许"安装未知来源应用"）。
2. 打开 App，进入 **三步引导**：
   - 第 1 步：昵称、性别、年龄、身高、当前体重；
   - 第 2 步：日常活动水平（影响每日热量预算）、健身目标（减脂 / 保持 / 增肌）、可选填目标体重；
   - 第 3 步：确认就绪，点击「开始使用」。
3. 完成后自动进入「今日」首页，App 会按 Mifflin-St Jeor 公式算出你的每日热量与三大营养素预算。

> 首次使用的初始体重会记入体重曲线；后续体重在「体重」页或首页快捷记录中更新。

## 2. AI 配置（一次配置，长期使用）

进入 **我的 → AI 配置**：

1. **添加接口**：点「添加接口」→ 点选快速预设（DeepSeek / 智谱 GLM / OpenAI），接口地址自动填好 → 粘贴你的 API Key → 保存。
   - DeepSeek 的 Key：打开 `platform.deepseek.com` → 注册 → API Keys → 创建并复制；
   - 智谱的 Key：打开 `bigmodel.cn` → 注册 → API 密钥 → 复制；
   - 其他任何「OpenAI 兼容」中转服务也可以：填对应的接口地址和 Key 即可。
2. **两个模型槽位**（可分别指定、可混搭不同家）：
   - **拍照识别食物**：需要一个视觉模型（支持图片输入），如 `glm-4.6v`、DeepSeek 当前视觉模型；
   - **生成训练计划**：普通文本模型即可，如 `deepseek-chat`、`glm-4.6`。
   - 每个槽位：选接口 → 填模型名 → 点「保存模型」→ 点「测试连接」确认绿色 ✓。
3. API Key **只保存在你手机 App 里**：不上传、不进代码仓库、**也不包含在备份文件中**（恢复备份后需重新粘贴一次 Key）。

## 3. 记录饮食（拍照识别卡路里）

**饮食** 页 → 右下角「记录饮食」→ 四种方式：

| 方式 | 操作 | 适合场景 |
| --- | --- | --- |
| 拍照识别 | 对着一餐拍照 | 最常用；拍清楚整桌/整碗 |
| 从相册选图 | 选一张已拍好的照片 | 补记前一餐 |
| 文字描述 | 输入如「一碗米饭+两个煎蛋+一杯豆浆」 | 不方便拍照时 |
| 手动录入 | 自己填名称与营养 | 明确知道数值时 |

- AI 识别后进入 **确认页**：逐条核对名称、克数、热量、蛋白质/脂肪/碳水（不确定的条目带 ❓ 提示），可修改、删除或再加一条；
- 选好餐次（早/午/晚/加餐）→ 「保存记录」；
- 确认过的食物会自动进入 **常吃食物库**（右上角入口），下次一键复用更准确；
- 饮食页支持切换日期补记：标题左右箭头。

> 提示：AI 估算有误差属正常，重要的是长期趋势一致——拍照角度和分量描述越具体，估算越准。

## 4. AI 生成并执行训练计划

**训练** 页（首次为空）→ 「AI 生成我的第一份计划」：

1. 填写：训练水平（新手/有基础/高级）、每周训练天数、每次时长、可用器材（如"只有哑铃和瑜伽垫"）、其他要求（如"想重点练腿"）；
2. AI 会结合你的 **身体档案 + 近 7 天平均摄入热量 + 体重趋势** 生成一周计划；
3. 预览无误 → 「保存并设为当前」（也可只保存不启用）。

**执行训练**：训练页点当天 → 「开始训练」→ 逐项打卡：
- 每个动作下方的组号 chip：点一下=该组完成；长按可修改该组实际次数/重量；「加一组」记录超出计划的部分；
- 动作打勾表示整个动作完成；页面顶部计时器自动累计时长；
- 「结束训练」→ 选训练感受（轻/刚好/累）→ 保存；历史页可查看每次明细。

## 5. 体重管理

**体重** 页：输入当天体重（一天多次记录自动覆盖为最后一次）；
- 顶部统计：当前 / 起始 / 目标 / 累计变化，目标进度条直观显示完成度；
- 趋势折线图展示近 90 次记录；右上角旗帜图标可设置目标体重。

## 6. 备份与电脑联动（数据安全）

数据只在手机本地 —— **建议每周备份一次**。**我的 → 备份与电脑联动**：

**手机 → 电脑（备份出去）**
1. 点「立即备份」生成 `.fitbak` 备份文件（每天 App 也会自动留最近 7 份本地备份）；
2. 点「分享最新备份（微信）」→ 发给 **微信「文件传输助手」** → 电脑微信打开另存到电脑。

**电脑 → 手机（恢复进来）**
- 方式一：电脑微信把 `.fitbak` 发给「文件传输助手」→ 手机微信点开该文件 → 「用其他应用打开」→ 选择健身管家 → 确认恢复；
- 方式二：App 内「导入备份恢复」→ 在系统文件选择器的"最近"里点选备份文件；
- 恢复时可选 **覆盖恢复**（清空后完全变成备份内容）或 **合并恢复**（保留本机数据，追加备份记录，计划导入为未启用）。

**局域网直传（备用，同一 Wi-Fi）**
- App 点「开启电脑传输服务」→ 显示地址（如 `http://192.168.1.5:41123`）→ 电脑浏览器打开该地址 → 网页上可「下载最新备份到电脑」或「拖入备份上传到手机」。

> 恢复前请确认备份文件来自可信来源；恢复完成后建议立即重启 App。

## 7. 常见问题

| 问题 | 处理 |
| --- | --- |
| AI 调用报「鉴权失败(401)」 | Key 填错或已失效，重新粘贴 |
| 报「余额不足(402)」 | 到对应平台充值或换免费额度模型 |
| 报「接口或模型不存在(404)」 | baseUrl 或模型名写错；用「测试连接」排查 |
| 拍照识别不准 | 换更清晰、光线好的照片；或改用文字描述+手动修正 |
| 换手机 | 新手机装 App → 电脑上的备份文件发到新手机微信 → 按第 6 节恢复 |
| 计划不合适 | 训练页 ⋮ → 计划管理可切换/删除多份计划；重新生成一份 |

## 8. 数据说明

- 所有数据（档案/饮食/训练/体重/计划/食物库）存于手机本地数据库；
- 备份文件 = zip 包（JSON 数据 + 食物照片），带格式版本校验；
- 卸载 App 会**清空全部数据**——卸载前请务必备份到电脑；
- 「我的 → 使用说明」内置同样的速查内容。
